夜色琉璃 Night Glass

图标的画法就是 UI 的画法：深色夜空里，玻璃容器盛着发光的原料。边界永远半透明白，光永远从左上来，发光永远是一种语义。

01

六条原则 — 每一条都对应图标里的一笔

左边是图标的原画法，右边是它翻译成 UI 后的样子。现场演示件都是活的 CSS，不是图片。

i去黑边 · 边界是光不是墨

图标：stroke="rgba(255,255,255,0.8)"

UI 边框只用半透明白（.12 常态 / .22 强调），绝不出现纯黑描边。

← 半透明白 ✓ ｜ 纯黑硬边 ✗

ii光从左上 · 受光面一律 135°

图标：linearGradient x1=0 y1=0 → x2≈.75 y2=1

所有渐变面（按钮、进度、选中底）都从左上亮、右下暗，绝不平涂。

135° 渐变
平涂 ✗

iii自发光 = 魔法 · 发光是语义

图标：feGaussianBlur + feMerge（仅魔法系）

UI 里只有强调/选中/稀有元素才带同色辉光；普通元素绝不发光——光一多就不值钱了。

← 发光=魔法 ｜ 不发光=真实

iv高光点缀 · 顶部一条呼吸线

图标：path stroke="#fff" opacity=".5"（瓶身光斑）

每张卡顶边 1px 渐隐白高光，暗示"玻璃表面"。点到为止，不做成大反光。

v环境光晕 · 主体背后一圈同色雾

图标：radialGradient 中心~0.2 → 边缘 0

选中态在元素背后垫一圈同色径向光（20~28% 起、边缘归零），让主体从夜色里浮出来。

← 光晕在主体后面，不在主体上

vi统一画布 · 网格即纪律

图标：viewBox 0 0 64 64，主体统一归一到 75%

UI 对应：圆角三档 10/18/26，间距 4 的倍数，图标在卡片里占宽 ~44%。先量后改，不靠肉眼。

← 4px 网格
