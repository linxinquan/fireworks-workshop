## 用户给过的「图标设计语言」（改/画图标一律遵守）
① **去黑边**：用 `rgba(255,255,255,0.8)` 半透明白描边，或同色系深色描边（不要 `#241407` 这种硬黑）。
② **渐变填充**：拒绝平涂，`linearGradient`，光从**左上**打下来（`x1=0 y1=0 → x2≈0.75 y2=1`）。
③ **自发光**：真实原料可不加，**魔法原料必须微微发光**（`feGaussianBlur` + `feMerge`）——这是真实/魔法的分界。
④ **高光点缀**：白色细线 / 小圆点。⚠️ 长而直的"高光"会被读成**划痕**；点在中间色调区会被读成**脏点**。
⑤ **环境光晕**：主体后方一枚极低透明度**同色径向**渐变圆（中心 ~0.2、边缘 0）。
⑥ **统一画布**：全部 `viewBox="0 0 64 64"`。

## 图标体系
- 两套并行：**剪影版**（32×32，为 17px 小尺寸而画，辨识度高）／**瓶罐版**（64×64，细节多，大图好看）。

## 验证方式（本项目的习惯）
用 `html-e2e-headless-check` skill 的 `cdp-run.js` 驱动 headless Chrome 测量/截图，先量后改，别靠肉眼猜。

两个踩过的截图坑（驱动里已固化）：
1. **卡片有入场动画**（`animation:in .35s both` + `animationDelay=i*22ms`，16 张累加到 ~680ms）。
   若在动画跑完前截图，后几排会是**半透明「幽灵卡」**——是截图时机问题，不是渲染 bug。
   截图类驱动一律先注入 `*{animation:none!important;transition:none!important}`。
2. **弹层截图要给足窗口**：CDP 轮询是 150ms/次，弹层至少保持打开 700ms 才稳。
   见 `checks/driver-v3-final.js`（关动画 → phase `grid` → 逐个点开弹层出 `sheet-<id>` 图）。

**SVG 三个隐形坑（改图标必查，详见 skill `svg-icon-craft`）**：
1. **`getBBox()` 不含元素自身 transform**。图标一旦用 `<g transform="translate(32,21)">` / `rotate()`，
   直接对各子元素 `getBBox()` 取并集会把不同坐标空间混在一起，量出**超过 viewBox 的假数**
   （月光花瓣曾量成 62×77，真实 33×53）。要经 `svg.getScreenCTM().inverse().multiply(el.getScreenCTM())`
   映射回 viewBox 坐标再并集（见 `checks/driver-v3-iconset.js` 的 `boxInViewBox()`）。
2. **`objectBoundingBox` 渐变在退化包围盒上完全不渲染**：x 恒定的竖直路径包围盒宽度=0，
   渐变元素**整条消失**（不是变浅）。改 `gradientUnits="userSpaceOnUse"` + 绝对坐标。
3. **`filter` 默认区域 = bbox 的 ±10%**：小图元（`r=2` 圆 + `stdDeviation=2`）模糊会被裁出**灰色方块**。
   统一写 `x="-100%" y="-100%" width="300%" height="300%"`。
   另注意反向陷阱：包围盒宽/高为 0 的元素套 `objectBoundingBox` 滤镜会整个不渲染。

**量体量时的历史数字更正**：星尘不是 40×18（漏算 `rotate(-15)`），真实 **43×26**。
